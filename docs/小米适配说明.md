# 小米/红米手机适配说明

本组件依赖后台刷新，HyperOS/MIUI 对第三方应用后台限制较严，必须手动授权，否则组件会「冻住」不更新。

## 1. 授权步骤（路径可能随系统版本略有差异）

设置 → 应用设置 → 应用管理 → 找到 **GanttCalendar** →

1. **自启动**：打开「自启动」开关
2. **省电策略**：设为「无限制」（不要用「智能省电」）
3. **后台运行**：允许后台运行（部分版本在「权限管理 → 后台弹出界面/后台运行」）
4. **锁屏后运行**：「其他权限」里允许后台运行

> 通用搜索：设置里搜「自启动」「省电策略」，逐个放开。

## 2. 添加组件

桌面空白处长按 → 添加小部件 → 搜索「GanttCalendar」→ 拖到桌面。

添加后**把组件拉大**到约 4 列宽 × 4~5 行高，否则 31 列每天太窄看不清。

## 3. 验收清单

| # | 步骤 | 期望 |
|---|---|---|
| 1 | 打开 App 新增几条跨天日程（如 9/5–9/10、9/8–9/15） | 列表显示正确 |
| 2 | 桌面添加组件 | 显示当前月份、色条位置/颜色/叠行正确 |
| 3 | 点击某根色条 | 打开**对应**那条日程的编辑页 |
| 4 | 点击组件上 `‹` / `›` | 月份切换，数据随之更新 |
| 5 | 重启手机后再看组件 | 仍停在上次月份 |
| 6 | 跨月日程（8/28–9/3，在 9 月视图） | 只画 9/1–9/3 那一段 |
| 7 | 当月无任何日程 | 显示空网格，不崩溃 |
| 8 | 删除/修改日程返回 | 组件立即刷新 |

## 4. 已知风险（待真机确认）

- 组件内单元格数量较多（最多约 31×12≈372 个 View），极端情况可能出现 `TransactionTooLarge` 或渲染卡顿；如遇异常，可调小 `GanttRenderer.MAX_ROWS`。
- 刷新走广播触发，一次数据变更可能触发两次刷新（幂等，无害）。
