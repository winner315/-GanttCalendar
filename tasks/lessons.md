# 踩坑记录

## 2026-10-23 · Web 版移植

### 1. Vite dev server 会缓存模块，新旧代码混着跑
改了 `MainLayout.vue`（加 `<BackupBar />`）后，Playwright 报 `waiting for locator('.topbar-slot button')` 超时，而直接 `curl` 源码明明是新版。
原因：端口上跑着**早前启动的旧 server 进程**，它内存里的模块图是编辑前的。
`pkill -f vite` 在 Windows 上无效；`Stop-Process` 和删 `node_modules/.vite` 都被权限策略拦下了。
**做法**：改用 `npx vite --port <新端口> --strictPort --force` 起一个干净进程，并把验收脚本的地址做成 `E2E_BASE` 环境变量。
**教训**：改完公共组件（被所有路由引用）后，验收前先换端口起新 server，别在旧进程上排除法找 bug。

### 2. antd 会给两字中文按钮插空格
「保 存」「删 除」「备 份」「清空筛选」在 DOM 里都可能带空格，`hasText: '保存'` 匹配不到。
**做法**：一律用正则 `/^保\s*存$/`。这次在「备份」上又踩了一遍 —— 记牢，别再用裸字符串匹配中文按钮。

### 3. 断言别绑定前序步骤的副作用
列表页「天数排序」写死了「版本迭代 6 天、联调测试 8 天」，但前面的拖拽用例已经把工期改成 9 天。
**做法**：天数从表格 DOM 里现读再断言大小关系，不写死数值。

### 4. 关闭后的 antd Modal 仍留在 DOM 里
`locator('.ant-modal-content').count() === 0` 在弹窗关闭后仍为 1（`display:none`）。
**做法**：判「没弹出来」用 `isVisible()`，不用 `count()`。

### 5. Locator 匹配范围要收窄
顶栏和甘特视图各有一个 `.ant-input-search`，`page.locator('.ant-input-search input')` 命中 2 个触发 strict mode 报错。
**做法**：`locator('.ant-input-search input').first()`，或用外层容器限定范围。

### 6. 用 sed 批量改正则字面量容易改坏
一条 `sed` 把 `/^确定覆盖$/` 写成了 `/^确定覆盖$//`，直接语法错误。
**做法**：涉及正则/引号转义的批量替换，用 Edit 逐条改，别图快用 sed。

### 7. 「只取第一条」这种兜底写法，在语义上就是错的
年视图缩略格子上一天有多条日程时只画了第一种颜色（`colorAt` 用 `if (!colorAt.has(d))` 只留第一条），大哥一眼看出来了。
**教训**：凡是「多个值挤一个位置」的地方，先问一句「剩下的值丢了会不会有人需要」，默认不是取第一个而是表示出来（切分/叠加/标条数）。

## 移植时值得记下的口径（非坑，但容易想当然）

- **日期用 `Date.UTC` 而不是 `new Date(y,m,d)`**：后者按本地时区构造，夏令时地区会算错一天。
- **色带上文字颜色不能照抄 Android 的「亮度 > 0.6 用白字」**：黄色底配白字对比度只有 1.81，改成取深/浅两色里对比度更高的那个。
- **节假日数据没覆盖的年份，普通周末不标角标**：宁可空着也不猜（沿用原版口径）。
- **筛选时间范围用「区间相交」而不是「完全包含」**：只筛 10 月却把 9/28~10/03 这条藏掉，与直觉不符。
- **休息日不区分法定假与周末**：同一种角标色 + 同一种格子底色。分色会让人以为红色那几天另有含义；补班日仍单独用蓝（语义相反）。
- **单条 e2e 用例造的数据要当场清掉**：临时加的「第三条彩带」没删，把后面 7 条列表页/备份断言全带崩了 —— 断言依赖数据条数时，用例之间要能独立。
